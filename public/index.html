Documentación de la API REST & Autenticación

Los métodos de modificación (POST, PUT, DELETE) requieren autenticación mediante el header HTTP x-api-key.

Header requerido: x-api-key: version-hub-secret-2026
GET /api/state Público

Obtiene el estado completo del sistema: provincias, aplicaciones y los despliegues asociados.

curl -X GET http://localhost:3000/api/state
POST /api/deployments Protegido

Actualiza un despliegue indicando la aplicación y la provincia (admite nombres o IDs). Envía "N/A" si no aplica.

curl -X POST http://localhost:3000/api/deployments \
  -H "Content-Type: application/json" \
  -H "x-api-key: version-hub-secret-2026" \
  -d '{"appId": "SQL", "branchId": "Salta", "version": "v2.6.0"}'
POST /api/apps/check-updates Protegido

Ejecuta la validación automática consultando las URLs de los repositorios configurados en cada aplicación.

curl -X POST http://localhost:3000/api/apps/check-updates \
  -H "x-api-key: version-hub-secret-2026"
POST /api/deployments/check-updates Protegido

Consulta las URLs JSON configuradas en cada provincia para actualizar las versiones automáticamente.

curl -X POST http://localhost:3000/api/deployments/check-updates \
  -H "x-api-key: version-hub-secret-2026"
